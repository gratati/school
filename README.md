🎓✨ Лицей №9 — Система

Интерактивная веб-история / квест в формате мини-игры про школьную систему, выбор роли и финальное сообщение.

🚀 О проекте

🎮 Это интерактивное одностраничное приложение (SPA), где пользователь проходит сценарий из 5 сцен и получает персональный результат.

📌 Основной акцент:

эмоции
кинематографичная подача
